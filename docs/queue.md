# Posting-Zeiten und Queue

Seit 0.9 werden Regeln pro Kanal gespeichert. Maßgeblich sind `posting-schedules.md`, API-Schema 3 und UI-State 2. Bestehende Termine werden nicht automatisch verschoben.
